Vulnerable Web Application Security Lab

Overview

A controlled Application Security assessment of OWASP Juice Shop, a deliberately vulnerable web application used for security training.

The purpose of this project is to develop practical skills in web application security, vulnerability assessment, security testing, vulnerability documentation and remediation.

Objectives

* Understand web application architecture and attack surfaces
* Perform application reconnaissance
* Identify and investigate OWASP Top 10 vulnerabilities
* Analyse vulnerability causes and potential impact
* Document security findings
* Develop remediation recommendations
* Improve secure software development practices

Security Testing Scope

Testing is performed only against the locally deployed OWASP Juice Shop laboratory environment.

Target:

http://localhost:3000

Areas of Assessment

* Authentication
* Authorization
* Input validation
* Web application security
* API security
* Session management
* Business logic
* OWASP Top 10 vulnerabilities

Methodology

1. Reconnaissance
2. Attack-surface identification
3. Vulnerability assessment
4. Controlled proof of concept
5. Impact analysis
6. Security documentation
7. Remediation analysis
8. Retesting

Tools

* OWASP Juice Shop
* Browser Developer Tools
* Git & GitHub
* Docker
* Burp Suite Community Edition — to be introduced during the assessment

Status

In Progress

This project is being developed as part of an Application Security learning and portfolio programme.

Ethical Use

All testing is conducted against a deliberately vulnerable application in a controlled local laboratory environment. No unauthorized systems or third-party applications are targeted.
